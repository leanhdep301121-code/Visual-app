# Swi 球描线 — 技术报告

> 纯手机、纯单目、全端上。视频进,球的 3D 弹道出。
> 2026-07-16

---

## 1. 推理链路

五个模型,全部 Core ML,全部端上跑,无联网。

| 阶段 | 模型 | 输入 → 输出 |
|---|---|---|
| 姿态 | **swipose** (yolo11n-pose golf 蒸馏, 320²) | 帧 → 17 关键点 |
| 事件分割 | **PoseTCN v3.1** | 64 帧姿态序列 → 8 个挥杆事件 |
| 球检测 | **TrackNet** (UNet 热力图) | 9 帧 + 中值背景 → 每帧热力图 |
| 几何标定 | **GeoCalib** | 单帧 → 地平线 → 俯仰 + 焦距 |
| 3D 弹道 | **BallFlightSolver** (非神经网络) | 2D 球迹 → 速度/发射角/carry |

```
视频 ─┬─→ swipose ──→ PoseTCN ──→ impact 帧 ─┐
      │                                      ├─→ 过滤 ─→ 球迹(2D)
      └─→ TrackNet ─→ 每帧候选 blob ─────────┘         │
                                                       ▼
     内参:自录用真内参 / imported 用 GeoCalib ──→ 3D 弹道拟合
                                                       │
                                                       ▼
                                          弧线 + 球速 + 发射角 + carry
```

**设计要点:impact 由 PoseTCN 提供,不靠球本身推断。** 这是全链路信噪比最高的
信号(夜间实测 softmax 0.97),整个过滤逻辑以它为支点。

---

## 2. 过滤:从热力图到球迹

TrackNet 用的是羽毛球权重(off-domain),对**任何高速运动的光流**都响应 ——
球、杆头、杆身拖影、背景杂物。过滤是这条链最难的部分,四道关:

**① 多候选** — 每帧保留所有 >0.5 的连通域,不选「最大面积」(会选到杆头)。

**② 弹道链** — 贪心链接:帧间步长 <0.14 可接;链长 ≥3 且净位移 >0.12 才算候选;
按 (净位移, 链长) 取冠军。静止物形成零位移链被剔,孤点连不上被剔。

**③ impact 门** — **球在 impact 之前不可能在飞**。impact 前的半空点必然是杆身
拖影,它们高度不变 → 反投速度趋零 → tee 位置爆炸。拟合观测只取 `t ≥ impact`;
链首若已在地面则直接采纳(那就是 address 球本身)。

> 实测:含杆身点 → tee 反投到画面外 x=-7229px、拟合失败;
> 剔除后 → tee x=811px(真球 802px)、39 m/s 出解。

**④ 平台剔除** — DTL 视角球往深处退,尾点图像位移趋零、无 3D 信息却主导拟合,
按步长中位数截断。

**退化护栏**:发射角 <2° 或 >44°、速度 ≥74 m/s、tee 反投出画面 → **不出 tracer**。
错线比没有更糟。

## 3. 物理引擎

不是神经网络,是**有界网格搜索 + 空气动力学积分**,4 个自由度:

```
speed / launch(10–42°) / azimuth(±28°) / t0(-0.30–0s)
网格搜 → 3 轮细化 → 重投影残差最小解
```

拟合用平地重力,**只在投影时用俯仰重力** —— 把俯仰塞进拟合网格会把最小值推向慢解。

### 空气动力学

半隐式欧拉 @1/240,二次阻力 + Magnus 升力。**Cd 和 Cl 都随自旋变化**,
用发射角作自旋代理,在实测锚点间插值:

| 发射角 | Cd | Cl | 参照 |
|---|---|---|---|
| 10.9° | 0.21 | 0.16 | PGA 驱杆 2686 rpm |
| 16.3° | 0.35 | 0.37 | PGA 7铁 7100 rpm |
| 20.0° | 0.33 | 0.31 | 业余 7铁 |

基准复现(carry / 顶高 / 滞空):

| | 模型 | 真实 |
|---|---|---|
| 驱杆 75 m/s | 260m / 31.2m / 6.6s | 256m / 32m / 6.4s |
| PGA 7铁 54 m/s | 158m / 32.1m / 6.5s | 158m / 32m / 6.3s |
| 业余 7铁 45 m/s | 128m / 21.5m / 5.2s | 130m / 22m / 5.0s |

> **这些是等效系数,不是实测气动量** —— 为让简化模型(无自旋衰减、无雷诺数
> 依赖)复现真实弹道而拟合。Cd 0.35 对真球偏高,它在替模型没建的部分买单。

## 4. 精度边界

**单目绝对尺度被身体尺子锁死在 ±20%。**

深度来自 `anchorZ = 焦距 × 1.62m / 躯干像素跨度` —— 假设球员身高。误差来自
**这个身高假设**,不是焦距。

- ✅ **方向、弧形、起点** —— 几何决定,可靠。端上实测轨迹正确。
- ❌ **绝对距离** —— 估的。调参调不出来。

打破尺度的真锚只有三条:**球径测深**(42.67mm 精确已知,address 球静止可见,
`深度 = f × 0.04267 / 球像素直径`,不依赖任何身高假设)、**杆头速度**、
**device 真内参 + IMU**。

产品上的处理:置信度不足时**不给数字**,只画轨迹 + 标注「距离未标定」。
球速和 carry 同源于尺度误差(carry≈v²),要藏一起藏。

## 5. 待实测 / 待优化

### 5.1 物理引擎:需要球场真值 ★
现在整条链是**先单目估、再重建**,估的部分太多。Cd/Cl 插值目前只在**三个教科书
基准**上对上,没有一杆真值。需要:

- **录 bag**:视频 + 手机真 IMU(重力/姿态)+ 真内参同步落盘。
  `cameraIntrinsicMatrixDelivery` 已接通,**自录杆的焦距是真的**,不用估。
- 用**真 IMU 重力**替掉 GeoCalib 的俯仰估计 → 才能把「引擎错」和「尺度错」分开。
  现在两者纠缠,任何调参都是盲调。
- 覆盖竖屏/横屏、白天/夜间、驱杆→短铁(拿自旋跨度检验 Cd/Cl 插值)。
- 配一次测距/雷达真值,哪怕十几杆,用来标定 anchorZ。

> 已知天花板:发射角当自旋代理是有极限的 —— PGA 7铁自旋高于业余 7铁,发射角却
> 更低。长期要么引入球杆选择,要么从球迹反解自旋。

### 5.2 Inference time:需要优化 ⚡
当前一条 clip(82 帧)**13.15s**。分解后结论很清楚:

```
pose extraction     0.49s
events + metrics    0.02s
club detect         1.36s   ← 零产出
ball trajectory     6.15s   ← decode 1.00 | median 2.19 | infer 0.12 | heatdecode 1.46
geocalib + fit      5.13s
             total 13.15s
```

**ANE 推理本身只有 0.12s。** 时间全花在推理以外 —— 数据搬运、数组循环、网格搜。
靶子明确:

| 靶子 | 现状 | 方向 |
|---|---|---|
| TrackNet median | 2.19s | 数组循环 → vDSP/Accelerate |
| TrackNet heatdecode | 1.46s | 逐元素读 MLMultiArray → 指针 + vDSP 阈值化 |
| TrackNet decode | 1.00s | 与 pose 共用一次解码 |
| geocalib + fit | 5.13s | 网格搜 SIMD 化 / 缩网格 |
| club detect | 1.36s | 删除 |

目标 **live 可跑**。(以上为 DEBUG 构建,Release 约 20× 快,但纯数组循环是结构性
开销,该改还得改。)

### 5.3 白天通路(尚未上端)
TrackNet 把 1080→512 缩图,3px 的球缩成亚像素直接消失。全分辨率 + 空间掩码 +
多候选 + 平滑抛物线选链 → 离线实测 14 点干净弹道(残差 0.0137)。待 Swift 移植。
